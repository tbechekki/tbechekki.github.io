About

This site is my coursework for ITIS3135, Front-End Web Application Development, taught by Professor D.I. von Briesen. His teaching site has the assignments, the standards, and the schedule.

I build and check my pages with a few tools: VS Code with Emmet for writing HTML and CSS, Git and GitHub for version control and publishing, an SFTP extension for my UNC Charlotte webspace, my browser's developer tools, and the Accumulus validator that sits on every page.

These are the sites I'll build this semester:

  • My personal home page, which introduces me and links to this course site.
  • This course site, with matching headers and footers on every page.
  • A design firm site, linked from the footer of every course page.
  • A crappy page that intentionally breaks every rule.
  • A whimsical product company site for my mascot.
  • A peer-management tool.
  • A client project.
